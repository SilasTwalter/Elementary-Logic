📖 Tutorial: How to Work with Logic Proofs

Step 1: Understand Propositions

A proposition is a statement that can be true or false. In logic, we combine them with connectors:

  • ∧ (and)
  • ∨ (or)
  • → (implies)
  • ↔ (if and only if)
  • ¬ (not)
Example: A ∧ B means “A and B are both true.”

Step 2: Make Assumptions

Sometimes, to prove a conditional, we assume the antecedent and see what follows. This is called conditional proof.

Example: Assume A. If you can derive B, then you can conclude A → B.

Step 3: Apply Rules

Inference rules let us move from known propositions to new ones. Here’s how each works in detail:

∧E (And Elimination)

If you know A ∧ B, you can take out either part. This is useful for breaking down complex statements.

1. A ∧ B (Premise)
2. A (from 1, ∧E)
3. B (from 1, ∧E)

∧I (And Introduction)

If you have both A and B separately, you can combine them into A ∧ B. This builds larger truths from smaller ones.

1. A (Premise)
2. B (Premise)
3. A ∧ B (from 1,2 ∧I)

→E (Conditional Elimination / Modus Ponens)

If you know A → B and you also know A, then you can conclude B. This is one of the most powerful rules in logic.

1. A → B (Premise)
2. A (Premise)
3. B (from 1,2 →E)

→I (Conditional Introduction)

If assuming A leads you to derive B, then you can conclude A → B. This requires discharging the assumption once the conditional is formed.

1. [Assume A]
2. B (derived)
3. A → B (from 1–2 →I, assumption discharged)

↔E (Biconditional Elimination)

If you know A ↔ B, then A and B always go together. From A, you can infer B, and from B, you can infer A.

1. A ↔ B (Premise)
2. A (Premise)
3. B (from 1,2 ↔E)

↔I (Biconditional Introduction)

If you can prove both A → B and B → A, then you can conclude A ↔ B.

1. A → B (Premise)
2. B → A (Premise)
3. A ↔ B (from 1,2 ↔I)

∨I (Or Introduction)

If you know A, you can always conclude A ∨ B for any B. This is useful for setting up disjunctions.

1. A (Premise)
2. A ∨ B (from 1 ∨I)

∨E (Or Elimination)

If you know A ∨ B, and from assuming A you can derive C, and from assuming B you can also derive C, then you can conclude C.

1. A ∨ B (Premise)
2. [Assume A] → C
3. [Assume B] → C
4. C (from 1–3 ∨E)

¬I (Negation Introduction)

If assuming A leads to a contradiction, then you can conclude ¬A.

1. [Assume A]
2. … derive contradiction (e.g., B and ¬B)
3. ¬A (from 1–2 ¬I)

R (Reiteration)

You can restate a line from within an open scope to use it again later. This keeps propositions available across steps.

1. A (Premise)
2. A (from 1, R)
